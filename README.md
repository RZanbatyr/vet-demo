# Демо-сайт ветклиники ARLAN VET (шаблон для показа клиентам)

Копия стоматологического демо (`../../Демо-сборка/сайт`) с другим контентом и медиа.
Видео 4 сцен и картинки мозаики сгенерированы: `../gen/gen_media.py` (Veo 3.1 Lite + Gemini 3.1 Flash Image, Vertex AI).

Ветклиника вымышленная: название, адрес, телефон, цены - ориентир для презентации.
Два языка: RU и KZ, переключатель в шапке.

## Запуск

```
npm install        - один раз
npm run dev        - локально, http://localhost:5173
npm run build      - собрать в dist/ (это и заливаем)
```

`dist/` весит ~17 МБ, из них 16 МБ - видео полёта по клинике (`public/scroll/vid/`).

## Что менять под реального клиента

Всё в одном файле `src/content.ts`: название и логотип, телефон, адрес, часы,
мессенджеры, тексты 4 сцен полёта (`heroScenes`), три бара первого экрана,
врачи, прайс, 8 страниц услуг (`pages`), тексты формы записи. Обе версии (ru, kz) рядом.

Фото и видео:
- `public/scroll/*.jpg` и `public/scroll/vid/*.mp4` - сцены полёта (нужны копии `-m` для телефона)
- `public/img/*.webp` - картинки мозаики (hero, section2, s3bg, s3img1, s3img2)

Форма записи сейчас только показывает «Спасибо». Для живого сайта подключить
Google Sheets + Apps Script по сниппету из проекта CRM.

## Деплой

`dist/` статический, base = `./`, открывается из любой подпапки:
GitHub Pages, Vercel, Netlify (`--no-build`).
